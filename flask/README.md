# Flask version (from the old cd6-map repo)

An early Flask server version of this map, first started in the separate `cd6-map` repo (June 2025).
That repo is now archived and its history is merged here.

- `src/app.py` — Flask app
- `templates/index.html` — page template
- `deploy.sh`, `update_and_push.sh` — the old deploy helpers

The live map is the static `index.html` at the root of this repo.
